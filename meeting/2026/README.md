
# Team Meeting Documentation

This folder contains records of team meetings.

---

## Structure 

Meetings are organized by year and then by meeting type. 

- `/meeting/2026/weekly_soft_deadline`
- `/meeting/2026/weekly_strict_deadline`

Each file follows the following format:

`YYYY_MM_DD_meeting_type.md`

Example:
- `2026_02_01_weekly_soft_deadline.md`
- `2026_02_01_weekly_strict_deadline.md`

---

## What Each Meeting Contains

Each meeting record includes:

- Meeting information
- Topics discussed
- Decisions made
- Open questions
- Action items (if any)
- Follow-up tasks (if any)

---

## Purpose

This ensures:

- Transparent team communication
- Clear decision tracking
- Accountability for actions
- Historical documentation
